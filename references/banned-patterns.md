# 禁用句式清单

按严重程度排序。前 6 条是硬禁，出现即改。

## 一级：语法制造悬念

### 1. 揭晓结构

冒号前面吊着，后面给答案。

- ✗ 变大、加料还能降价，通常只有一个原因：它被打了。
- ✗ 答案很简单：销量。
- ✗ 说穿了就一句话……
- ✓ 变大、加料还能降价，原因在销量上。星愿 46.58 万辆，海鸥 31.1 万辆。

### 2. 孤立短句成段

- ✗ 五十一辆。
- ✗ 它被打了。
- ✗ 然后呢。
- ✓ 观致 2014 年在欧洲卖出 51 辆。

### 3. 标签式短句

段落开头用"谁怎么样"代替"谁做了什么"。

- ✗ 硅谷支持他。
- ✗ 华盛顿不同意。
- ✗ 这个价位很尴尬。
- ✓ 在硅谷，帮他说话的人不少。
- ✓ 华盛顿那边的态度不一样。

### 4. 拟人化动词套在组织上

- ✗ 市场用脚投票 / 车企睡不着觉 / 它被打了 / 资本不信固态
- ✓ 市场份额从 35% 降到 21%

### 5. 比喻升华

- ✗ 这不是一场胜利，是一次退潮之后露出来的礁石。
- ✗ 一场宏大的真人秀
- ✓ 新能源份额上升，主要因为燃油车下滑更快。

> 例外：比喻用于解释机制，且每 1500 字不超过 1 个，可以用。

### 6. 二元对仗

- ✗ 不是 A，而是 B（密度必须为 0）
- ✗ 一个是天上，一个是地下
- ✓ 老款 X、Y、Z；新款 A、B、C。

### 7. 结尾升华

- ✗ 未来可期 / 让我们拭目以待 / 写在最后 / 这才是真正的开始

## 二级：无主语与名词化

### 8. 抽象名词当主语

- ✗ 换代的主要变化在尺寸和底盘。
- ✗ 版本分五档。
- ✗ 全系标配包括……
- ✓ 这次换代，比亚迪主要改了尺寸和底盘。
- ✓ 海鸥有五个配置。

### 9. 结果当主语

- ✗ 后排空间主要来自轴距增加的 150 毫米。
- ✓ 比亚迪把轴距加长了 150 毫米，后排空间跟着变大。

### 10. 无主语的省略

- ✗ 仪表盘取消了。/ 装载方面，新增 94 升前备箱。
- ✓ 比亚迪把仪表盘取消了。/ 比亚迪在前舱加了 94 升前备箱。

### 11. 名词化

- ✗ 轴距的增加 / 配置的下放 / 体验的提升 / 成本的优化
- ✓ 把轴距加长 / 把配置给到低配 / 让体验变好 / 把成本压下去

### 12. 书面连接词

- ✗ 从产品变化看 / 就……而言 / 在……方面 / 对于……来说
- ✓ 直接写主语和动作

## 三级：评论腔

### 13. 空转过渡

- ✗ 值得注意的是 / 与此同时 / 此外 / 换句话说 / 说白了
- 每种每篇 ≤1 次，最好不用。

### 14. 无依据定性

- ✗ 这次改得很有诚意 / 表现相当出色 / 诚意十足
- ✓ 后驱加独立悬架通常出现在 10 万元以上，这里放到了 7 万级。

### 15. 情绪副词

- ✗ 令人唏嘘 / 不禁 / 竟然 / 偏偏 / 恰恰 / 无疑

### 16. 万能总结

- ✗ 综上所述 / 总的来说 / 由此可见 / 不难发现

### 17. 行业黑话

- ✗ 赋能 / 抓手 / 闭环 / 心智 / 生态位 / 护城河 / 底层逻辑
- 允许出现，但必须紧跟一句人话解释，每篇 ≤2 次。

## 四级：凑字数

### 18. 补充说明句

主句已经说完，再补一句强调。

- ✗ 这些行动他本人是支持的。
- ✗ 这一点很重要。
- ✗ 这不是小事。

### 19. 背景复述

读者已经知道的事，正文里再讲一遍。判断标准：本地读者昨天在别的号上看过没有。

### 20. 设问与感叹

- ✗ 为什么我要说……？ / 你品，你细品 / 一点都不丢人好嘛
- 感叹号一律不用。

## 附：自查口诀

> 句首是人不是词，动词落地不成"化"。
> 数字别单独成段，答案别藏在冒号后。
> 评价句放在段末，带个"我"字更像人。
