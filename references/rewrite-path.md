# 改稿三步

拿到任何一版稿子，按顺序过三遍。每遍只做一件事，不要混着改。

## 第一步：去悬念

**找什么**：靠语法制造紧张感的句子。

按 `banned-patterns.md` 一级清单逐条搜：

- 冒号后面给答案 → 把答案提到句首
- 数字或名词单独成段 → 并回上一段
- 段首标签句（"硅谷支持他。"）→ 补上动作
- 拟人化动词 → 换成谁做了什么
- 比喻升华 → 换成对比陈述
- 结尾"未来可期" → 换成带条件的判断

**判断标准**：删掉这句话，信息有没有损失？没有就删。

**改完的效果**：句长变异系数从 0.55 以上降到 0.45 左右，短句占比接近 0。

## 第二步：去名词化

**找什么**：句首是"……的+名词"，或者主语是抽象概念。

- 「X 的主要变化在 Y」→「谁把 X 改成了 Y」
- 「后排空间主要来自轴距增加的 150 毫米」→「把轴距加长了 150 毫米，后排空间跟着变大」
- 「装载方面，新增……」→「谁在前舱加了……」
- 「成本优化」→「把成本压下去」

**动词替换表**：

| 名词化 | 动词化 |
|---|---|
| ……的增加/提升/优化 | 加长、拉高、压低 |
| ……的下放/普及 | 给到、装到低配上 |
| ……的取消/削减 | 砍掉、删了 |
| ……的实现 | 做到了、跑到了 |

**改完的效果**：名词化密度降到 1.0 以下。

## 第三步：补第一人称判断

**找什么**：中立口吻的评价句。

信号词：从……看、就……而言、是否值得要看……、补得是否到位要看……、属于……、算得上……

**改法**：把"评价"换成"我的反应"。

| 中立评价 | 第一人称 |
|---|---|
| 这套改动在同级不常见 | 看到后驱和独悬出现在 7 万级，我第一反应是有点意外 |
| 按配置分布，飞翔版最划算 | 要我自己掏钱，会选飞翔版 |
| 是否值得要看使用场景 | 值不值这 1.7 万，我自己也没想清楚 |
| 后排长途舒适性不足 | 我在后排待了十几分钟就想往前挪 |
| 补得是否到位要看销量 | 补得够不够，我心里没底 |

**位置**：只放在段末。信息段中间不要插"我觉得"。

**改完的效果**：1500 字里出现 6–8 个"我"，且全部在评价位。

## 收尾自检

```bash
python3 scripts/check.py 你的稿子.md
```

对照 `calibration.md` 的目标区间。哪项不达标，回对应那一步改，不要动内容。

## 常见返工

| 现象 | 原因 | 回哪一步 |
|---|---|---|
| 读起来发木、平 | CV 低于 0.38 | 第二步改过头了，把个别句子拆开，但不要拿短句当鼓点 |
| 读起来像报告 | 名词化 > 1.5 | 第一步没做干净 |
| 读起来像评论员 | "我"少于 3 次 | 第三步没做 |
| 读起来像自我表演 | "我"多于 12 次 | 第三步做过头 |
| 读起来像配置表 | 数字密度 > 100 且无判断 | 在数字段之间插评价句，或砍参数 |
