# 校准数据

同一篇素材的四次改写，用来回归测试。新稿写完跑一次 `scripts/check.py`，跟这张表比对。

## 四版对比

素材：一篇 2000 字左右的车型评测。

| 指标 | 悬念版 | 流水式 | 正序版 |
|---|---|---|---|
| 平均句长 | 36.3 | 31.3 | 33.8 |
| 句长 CV | 0.58 | 0.42 | 0.41 |
| 长句 ≥50 字 | 31.5% | 11.1% | 16.7% |
| 短句 ≤8 字 | 9.3% | 0.0% | 2.1% |
| 平均段长 | 64.9 | 68.5 | 69.5 |
| 名词化密度 | 1.49 | 0.63 | 0.60 |
| 字数 | 2013 | 1575 | 1668 |

## 每一版改了什么

**悬念版 → 流水式**：删揭晓结构、删孤立短句、删拟人化、删升华。
CV 0.58 → 0.42，短句 9.3% → 0。

**流水式 → 正序版**：把"X 的主要变化在 Y"改成"谁把 X 改成 Y"。
名词化 1.49 → 0.60，跌六成。

## 目标区间与危险线

| 指标 | 目标 | 危险线 |
|---|---|---|
| 平均句长 | 28–36 | <25 太碎，>40 太闷 |
| 句长 CV | 0.40–0.50 | <0.38 发木 |
| 长句 ≥50 字 | 8%–16% | >20% 变报告 |
| 平均段长 | 60–90 | <50 碎片化 |
| 名词化 | ≤1.0 | >1.5 报告腔 |
| 数字密度 | 25–90（参数题可放宽） | >100 配置表 |

## 已知偏离项

**参数型选题数字密度压不下去。** 新车评测天然在 90–130。要压到 90 以下只能砍参数，文章会短一半。这是题材决定的，不算失误，但要在数字之间穿插判断。

**短篇（<600 字）CV 容易偏高。** 样本少，一两句短判断句就能把方差拉上去。

**名词化检测是近似。** `check.py` 用固定的几个模式匹配，覆盖不了所有名词化写法，也可能误判。到处名词化的稿子，这一项会明显偏高，可以当作提示。
